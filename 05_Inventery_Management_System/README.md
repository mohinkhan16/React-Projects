# 📦 Inventory Management System

A simple and interactive Inventory Management System built with React.js and Redux Toolkit.

## 🌐 Live Demo

**[View Live Project](https://react-projects-ruby-eight.vercel.app/)**

## 🚀 Features

- Add new products
- View all products
- Edit existing products
- Delete products
- Search products by name
- Sort products in ascending or descending order
- Manage global state using Redux Toolkit
- Dynamic inventory updates

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- Redux Toolkit
- React Redux
- HTML5
- CSS3
- Vite

## ⚙️ Installation & Setup

**1. Clone the repository**

```bash
git clone https://github.com/mohinkhan16/React-Projects.git
```

**2. Navigate to project folder**

```bash
cd React-Projects/05_Inventery_Management_System
```

**3. Install dependencies**

```bash
npm install
```

**4. Start development server**

```bash
npm run dev
```

**5. Open in browser**

```text
http://localhost:5173
```

## 📋 Product Information

Each product contains:

- Product ID
- Product Name
- Quantity
- Price
- Category
